# Política de seguridad

## Alcance

Este repositorio contiene exclusivamente **documentación en Markdown** y ejemplos de código educativos. No incluye servicios en producción, bases de datos ni manejo de datos de usuarios.

## Reportar una vulnerabilidad

Si encuentras un problema de seguridad (por ejemplo, un ejemplo de código que promueve prácticas inseguras, o una dependencia comprometida en los workflows de CI), por favor **no abras un issue público**.

Envía un reporte privado a través de la función **"Report a vulnerability"** de GitHub (Security → Advisories → New draft security advisory) o contacta directamente al mantenedor.

Responderemos en un plazo de 7 días hábiles.
